# GPT PC Cloud — ระบบคลาวด์ส่วนตัว

แอปเว็บฝั่งเซิร์ฟเวอร์สำหรับบัญชีผู้ใช้และจัดเก็บไฟล์บน PostgreSQL ใช้จากเบราว์เซอร์มือถือและคอมพิวเตอร์ได้

## ความสามารถ
- สมัครสมาชิกและเข้าสู่ระบบด้วยรหัสผ่านที่แฮชด้วย bcrypt
- เซสชัน JWT ในคุกกี้ HttpOnly และ SameSite=Strict
- บัญชีแต่ละคนเห็น ดาวน์โหลด และลบได้เฉพาะไฟล์ของตัวเอง
- ไฟล์ถูกเก็บใน PostgreSQL ไม่ใช่ดิสก์ชั่วคราวของเว็บเซิร์ฟเวอร์
- จำกัด 10 MB ต่อไฟล์ และ 100 MB ต่อบัญชีในรุ่นแรก
- Health check ที่ /healthz และจำกัดอัตราคำขอ
- หน้าจอภาษาไทย รองรับมือถือ

## Deploy บน Render
ไฟล์ render.yaml กำหนด web service แบบ always-on starter และ PostgreSQL แผน Basic-256 MB ในภูมิภาค Singapore ซึ่งมีค่าใช้จ่ายตามราคาปัจจุบันของ Render (ราคาอาจเปลี่ยนแปลง) Blueprint จะขอให้ใส่ OWNER_EMAIL และ OWNER_PASSWORD ในขั้นตอนตั้งค่า ห้ามใส่รหัสผ่านลงใน Git หรือแบ่งปันต่อสาธารณะ

## ความปลอดภัยและข้อจำกัด
- รหัสผ่านถูกเก็บเป็น bcrypt hash; เซสชันใช้คุกกี้ HttpOnly/SameSite=Strict
- จำกัดไฟล์ 10 MB ต่อไฟล์ และโควตา 100 MB ต่อบัญชี
- ไฟล์เก็บเป็น BYTEA ใน PostgreSQL เหมาะกับไฟล์ขนาดเล็ก ยังไม่ใช่ object storage ที่ขยายได้ไม่จำกัด
- รุ่นแรกยังไม่มี email verification, password reset, malware scanning, file versioning หรือ sharing links
- ควรเพิ่มระบบสำรองข้อมูลและทดสอบการกู้คืนก่อนเก็บข้อมูลสำคัญหรือเปิดให้คนจำนวนมากใช้
- บริการฟรีของ Render พักเมื่อไม่มีการใช้งาน และฐานข้อมูลฟรีมีวันหมดอายุ จึงไม่ใช้แผนฟรีใน Blueprint นี้สำหรับ 24/7 จริง
